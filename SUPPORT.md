# Support

Use GitHub Issues for reproducible defects and feature requests after checking the README,
requirements, and existing issues.

For usage questions, include the operating system, Python version, installation command, model
server type, and sanitized error. Never post API keys, passwords, uploaded documents, raw Debug
records, local paths containing personal information, or model prompts with private content.

Security problems must follow [SECURITY.md](SECURITY.md) and must not be reported publicly.
